# Dr. Biciusca Raluca — website

Site pentru CMI Dr. Biciusca Raluca (Roman, Neamț), construit cu Next.js 14, TypeScript,
Tailwind CSS și Framer Motion.

## Dezvoltare locală

```bash
npm install
npm run dev
```

## Structură

- `app/` — layout, pagina principală și ruta API pentru formularul de programare
- `components/` — secțiunile site-ului (Hero, Despre, Servicii, Filosofie, Recenzii, Contact, Footer)
- `lib/site.ts` — toate datele confirmate ale cabinetului (contact, program, servicii)

## Notă despre conținut

Toate datele publicate (nume, adresă, telefon, program, rating) provin din informațiile
confirmate de client. Fotografia doctoriței și recenziile scrise, integrale, sunt marcate ca
locuri rezervate ("placeholder") până când sunt furnizate de cabinet.
